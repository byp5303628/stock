# 财报指标存储 — 测试用例

## 测试概览

| 维度 | 内容 |
|------|------|
| 接口总数 | 7 个 |
| 接口用例数 | 30 个 |
| 端到端场景数 | 4 个 |

## 测试环境与数据

### 基础 URL

```
http://localhost:8080
```

### 测试数据规范

| 数据项 | 值 |
|--------|-----|
| 股票代码 | `000001`（平安银行）、`600519`（贵州茅台） |
| 报表类型枚举 | `BALANCE`, `INCOME`, `CASH_FLOW` |
| 报告日期 | `2024-12-31`, `2024-09-30`, `2024-06-30`, `2024-03-31` |
| 报告期枚举 | `Q1`, `Q2`, `Q3`, `Q4`, `YEARLY` |
| 指标值 | DECIMAL 类型，保留 2 位小数 |
| 唯一标识后缀 | 测试用例中使用 `${UNIQUE_SUFFIX}` 标记，执行时替换为 UUID/时间戳，避免并行冲突 |

### 通用预期响应结构

```json
{
  "code": 200,
  "msg": "成功",
  "data": { ... }
}
```

### 通用错误响应结构

```json
{
  "code": 40001,
  "msg": "错误描述信息",
  "data": null
}
```

## 接口测试

### API-01 POST /api/financial-reports — 创建/更新单条财报数据

#### 用例 1.1：正常创建财报数据

**描述**：创建一条完整的资产负债表数据，验证所有字段正确保存。

**请求**：

```bash
curl -X POST 'http://localhost:8080/api/financial-reports' \
  -H 'Content-Type: application/json' \
  -d '{
    "code": "000001",
    "reportType": "BALANCE",
    "reportDate": "2024-12-31",
    "reportPeriod": "Q4",
    "fiscalYear": 2024,
    "currency": "CNY",
    "unit": "元",
    "source": "TEST_SOURCE",
    "reportData": {
      "total_assets": 1000000000.00,
      "current_assets": 600000000.00,
      "cash_and_equivalents": 200000000.00,
      "accounts_receivable": 150000000.00,
      "inventory": 100000000.00,
      "non_current_assets": 400000000.00,
      "fixed_assets": 300000000.00,
      "intangible_assets": 50000000.00,
      "total_liabilities": 400000000.00,
      "current_liabilities": 250000000.00,
      "non_current_liabilities": 150000000.00,
      "accounts_payable": 80000000.00,
      "total_equity": 600000000.00,
      "share_capital": 500000000.00,
      "retained_earnings": 80000000.00
    }
  }'
```

**预期响应**（HTTP 200）：

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "id": 1,
    "code": "000001",
    "reportType": "BALANCE",
    "reportDate": "2024-12-31",
    "reportPeriod": "Q4",
    "fiscalYear": 2024,
    "currency": "CNY",
    "unit": "元",
    "reportData": {
      "total_assets": 1000000000.00,
      "current_assets": 600000000.00,
      "cash_and_equivalents": 200000000.00,
      "accounts_receivable": 150000000.00,
      "inventory": 100000000.00,
      "non_current_assets": 400000000.00,
      "fixed_assets": 300000000.00,
      "intangible_assets": 50000000.00,
      "total_liabilities": 400000000.00,
      "current_liabilities": 250000000.00,
      "non_current_liabilities": 150000000.00,
      "accounts_payable": 80000000.00,
      "total_equity": 600000000.00,
      "share_capital": 500000000.00,
      "retained_earnings": 80000000.00
    },
    "gmtCreate": "2024-12-31 23:59:59",
    "gmtModified": "2024-12-31 23:59:59"
  }
}
```

**验证点**：
- [ ] HTTP 响应状态码为 200
- [ ] `data.id` 不为 null，为自增正整数值
- [ ] `data.code` 与请求中的 code 一致
- [ ] `data.reportType` 与请求中的 reportType 一致
- [ ] `data.reportDate` 与请求中的 reportDate 一致
- [ ] `data.reportPeriod` 与请求中的 reportPeriod 一致
- [ ] `data.fiscalYear` 与请求中的 fiscalYear 一致
- [ ] `data.reportData` 中的每个字段值精确匹配请求
- [ ] `data.gmtCreate` 和 `data.gmtModified` 不为空

  "msg": "成功",
  "data": {

        "code": "000001",

        "reportDate": "2024-12-31",

        "fiscalYear": 2024,

        "id": 2,
        "code": "000001",
        "reportType": "INCOME",
        "reportDate": "2024-12-31",
        "reportPeriod": "Q4",
        "fiscalYear": 2024,
        "reportData": { "...": "..." }
      }
    ],
    "total": 2,
    "page": 1,
    "size": 20
  }
}

**验证点**：
- [ ] 返回的 `items` 中所有记录的 `code` 都是 `000001`

## 数据库验证查询合集

执行任何写入测试后，可通过以下 SQL 查询验证数据正确性：

```sql
-- 按唯一键查询
SELECT * FROM financial_report WHERE code = '000001' AND report_type = 'BALANCE' AND report_date = '2024-12-31';

-- 查询某种股票的全部财报
SELECT * FROM financial_report WHERE code = '000001' ORDER BY report_date DESC;

-- 验证去重约束
SELECT code, report_type, report_date, COUNT(*) as cnt
FROM financial_report
GROUP BY code, report_type, report_date
HAVING cnt > 1;

-- 分页查询
SELECT * FROM financial_report WHERE code = '000001' ORDER BY gmt_create DESC LIMIT 0, 20;

-- 查询最新的三种报表类型各一条
SELECT f.* FROM financial_report f
INNER JOIN (
  SELECT report_type, MAX(report_date) as max_date
  FROM financial_report WHERE code = '000001'
  GROUP BY report_type
) t ON f.report_type = t.report_type AND f.report_date = t.max_date
WHERE f.code = '000001';
```
